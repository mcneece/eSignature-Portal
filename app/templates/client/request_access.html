    Request Access

    Access to Adobe Acrobat Sign requires submitting a Secure request for a specific group membership.

    Request Access
    Secure Request Demonstration
    Acrobat Sign Secure Request
    To start the Secure Request Process visit Secure.uhc.com
    1. Click 'Add Group Membership'
    2. Request for: Select 'Platform'
    3. Platform: Select 'windows' (this is always windows even if you have a MAC)
    4. Platform: Select 'MS'
    5. Environment and Resource will auto populate to Prod and MS (leave this as is)
    6. Next select the user ID you wish to apply group assignment
    7. Search for group: 'dtm_esignature'
    8. From Available Groups select 'dtm_esignature'. Once selected, click the right arrow to move dtm_esignature to Selected Groups
    9. click 'Next'
    10. For Access Expires: Select 'Permanent'
    11. Supply a business justification
    This secure request requires approval from the eSignature Support Team and the submitters manager!
